# IMPREDESC

Plataforma de precificação e gestão para microempreendedores.

## 🚀 Como rodar o projeto

1. Instalar dependências:
```bash
npm install
```

2. Rodar servidor de desenvolvimento:
```bash
npm run dev
```

3. Abrir no navegador:
```
http://localhost:5173
```

## 📦 Funcionalidades

- ✅ Cadastro de insumos e estoque
- ✅ Precificação inteligente com margem ou markup
- ✅ Cálculo de mão de obra
- ✅ Análise de custos fixos e variáveis
- ✅ Histórico de receitas e produtos salvos

## 🛠️ Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite
- Motion (Framer Motion)
- Lucide Icons
